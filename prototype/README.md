# 产品原型（HTML 高保真交互原型）

单页原型，无构建依赖，纯静态三件套 + 本地图标库，可离线打开。

## 如何查看

- 方式一：直接双击 `index.html`（无任何网络依赖，图标库已内嵌本地）；
- 方式二：起个本地服务（避免个别浏览器对 file:// 的限制）：
  ```
  node .serve.js   # http://127.0.0.1:8437
  ```

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部视图骨架（登录 / 连接向导 / 建库向导 / 管理台 6 页 / 专家模式 / 自助改密） |
| `prototype.css` | 设计系统：配色、组件（按钮/表格/抽屉/步骤条/徽章/术语气泡等） |
| `prototype.js` | 模拟数据 + 全部交互逻辑（视图切换、树、抽屉、导入向导、冲突演示等） |
| `assets/lucide.min.js` | lucide 线性图标库 v0.454（离线内嵌） |
| `.serve.js` | 临时静态文件服务（演示用） |

## 覆盖的界面（右下角「原型导航」浮球可直达）

1. **登录页**：bind 登录，含术语白话气泡（bind / DN）
2. **连接向导**（3 步）：服务器信息 → rootDSE 自动探测（含空目录提示）→ 加密保存档案
3. **建库向导**（4 步）：base DN → 结构模板（LAM 经典 / 企业部门制 / 极简）→ 管理员 → 完成
4. **管理台**：
   - 概览：KPI、快速开始清单、目录健康状态（与 LAM 并存提示）
   - 组织与人员：左树右表 + 人员编辑抽屉（含重置密码、禁用、调动部门、entryCSN 冲突演示）
   - 用户组：权限组 / 登录组（groupOfNames / posixGroup 场景化）
   - 导入导出：Excel 四步向导（模板 → 上传 → **确认计划（含错误行）** → 执行动画 + 报告）
   - 审计日志：操作人 / IP / DN / 结果
   - 连接设置：档案、服务端能力探测、安全操作
5. **专家模式**：DN 分段路径、objectClass 徽章、属性表、LDIF 视图、entryCSN 说明
6. **自助改密页**：独立入口，密码强度条，六种密码策略错误提示（点击底部徽章演示）
7. **帮助中心**（2026-09-23 新增，侧栏第 7 项，规划见 `docs/plan-2026-09-23-新手引导-LDAP教学-对接指引.md`）：
   - 新手引导：6 步上手任务清单（完成态实时推断）+ 5 步聚光灯界面导览（自研，无第三方库）+ 空目录空状态设计
   - LDAP 教学：7 节课程全用本目录真实数据举例（DN 拆解 / objectClass / 多值属性 / bind 与权限 / 过滤器 / 两种组 / 常见误区），第 5 课内嵌**过滤器实验器**（迷你 RFC2254 解析器，语法错误模拟错误 21 白话提示）
   - 对接指引（核心）：对外通告地址提醒 → 5 种产品模板（堡垒机/零信任/VPN/SSO/通用）→ 按对方表单分组的信息卡（逐行复制 + 一键复制全部）→ **对接专用只读账号**（一次性密码 + 凭据自测含错误密码演示 + ACL 样例 LDIF）→ 接入验证与 FAQ 排错
   - 术语词典：29 属性 + 10 对象类词条，搜索 + 属性/对象类切换
   - 概览「快速开始」同步升级为 6 步，末步直达对接指引

## 设计规范

- **图标：全站单色线性图标（lucide，stroke 描边），禁用彩色/填充图标**；Logo 为线性描边的目录树图形（SVG 内嵌，蓝色 #2F54EB 单色）。
- 配色：主色 #2F54EB，灰阶文字 #1F2329/#646A73/#8F959E，状态色绿/橙/红仅用于徽章与提示背景。
- 中文优先文案，LDAP 术语首次出现处挂白话气泡（`.term` CSS tooltip）。
- 所有数据为前端模拟（12 名人员 / 5 个组 / 3 级部门树），与需求文档 R1–R11 对应关系见界面文案。

## 已知边界（原型层面）

- 不做真实 LDAP 连接；「执行导入」为定时器动画。
- 响应式仅保证 ≥1100px 桌面宽度（管理台类产品的主场景）。
- 手机端未适配。
