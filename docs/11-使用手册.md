# 使用手册（管理员）

适用版本：v1.x ｜ 面向：目录管理员 / 运维。员工自助改密见文末。

---

## 1. 登录

浏览器打开管理台地址 → 填 **Bind DN**（管理员账号，如 `cn=admin,dc=example,dc=cn`）与密码。

- 登录就是一次真实 bind：你在界面里能做什么 = 这个账号在 OpenLDAP 服务端的 ACL 权限，本工具不额外设限也不额外放权。
- 首次独立部署会自动进入**连接向导**（服务器地址 → 自动探测 Base DN → 验证账号 → 加密保存）。

## 2. 概览

- KPI：人员总数 / 部门 / 用户组 / 今日变更（含 LAM 侧写操作）。
- **快速开始**：6 步上手清单，完成状态实时从目录推断（不存"已读"状态）；最后一步直达对接指引。
- 目录状态：连接、Base DN、凭据加密方式、entryCSN 保护、phpLDAPadmin 跳转。

## 3. 目录树（左栏）

- 树就是 LDAP 目录本身（DIT）：部门（ou=）、组（cn=）都是树上条目，与 phpLDAPadmin / LAM 实时互见。
- **根节点「全部」**：点它查看全组织人员。
- 部门行显示英文名 + 中文别名（灰色后缀，存于第二个 ou 值）+ 子条目计数。
- **拖拽排序**：同层部门拖动调整顺序，顺序写入 ouOrder 属性（LAM 可见）。
- 部门行悬停出现 ➕：在此部门新建人员（自动预选该部门）。
- 📁＋ 新建部门：上级可选根（=顶级 OU）或任意部门；可同时填中文名与说明。
- 「更多」菜单：编辑部门信息（中文名 / 说明）、删除（有子条目时会先预览并要求处理）。

## 4. 组织与人员

- 表格：姓名 / 账号 / 工号 / 邮箱 / 手机 / 状态（在职 / 已禁用）/ 部门等。
  - **自定义列**：右上设置里勾选展示列（8 种可选）并 ▲▼ 排序；列宽可拖动。
  - 顶部搜索框：关键字过滤；顶栏全局搜索（任意页）回车进入搜索模式，点结果直接打开详情。
- **新建人员**：姓名 → 账号（必填；「按姓名生成」自动全拼 + 冲突自动加序号 + 防抖查重提示）→ 部门 → 工号/邮箱/手机/职务。创建成功同窗展示**初始密码**（只显示一次）。
- **人员详情抽屉**（简单模式）：改资料、重置密码、禁用/启用、调动部门（=移动条目）、所属组反查。
  - 改账号（uid）= 重命名条目（DN 变化），界面自动处理。
  - 禁用 = 密码失效（条目保留，可随时启用）；删除 = 永久移除，二者别混用。
- **勾选批量移动**：多选 → 批量移动到部门。
- **Excel 导入**：见「导入导出」页，四步向导（模板 → 上传 → 计划预览含错误行 → 执行 + 初始密码清单）。

## 5. 用户组

- 两类组，场景决定形态：
  - **权限组**（groupOfNames）：授权场景（VPN / 堡垒机 / 应用），成员存完整 DN，至少 1 名（schema 必填）。
  - **登录组**（posixGroup）：Linux 登录，gidNumber 自动分配（5000-5999），成员存 uid。
- 新建：选场景 → 组名 → （权限组）远程搜索选首名成员 → 说明。
- 成员维护：远程搜索人员添加（不用手敲 DN）、移除；组条目详情里可改说明、查看成员列表。
- 组条目（cn= 开头）在详情抽屉中呈现「条目信息」视图（不会误编辑成人员字段）。

## 6. 条目编辑（专家模式）

顶栏切到专家模式后，树/表格点开的抽屉即为专家视图：

- **属性**页：必填 / 可选 / 未知属性分组，uid 固定置顶；可新增属性行；悬停 ? 看中文说明。
- **对象类**页：主类卡片（可更换）+ 辅助类增删；人员可追加 posixAccount（Linux 登录）。
- **操作属性**页：entryUUID / entryCSN / 创建者 / 时间戳等服务器维护属性（只读）。
- **LDIF** 页：当前条目的 LDIF 视图。
- 保存按**属性级**提交（只改真正变过的属性），保存前与 entryCSN 比对，他人（如 LAM）先改过则提示刷新而非覆盖。

## 7. 导入导出

- 模板：中文表头 Excel；部门与人员分表，支持多级部门（导入时自动创建路径）。
- 计划预览会列出每行动作（新建 / 更新 / 错误原因），确认后才执行；执行报告含每人初始密码（仅此一次展示）。
- 导出：人员 Excel，自动剔除密码与哈希。

## 8. 审计日志

全操作留痕：时间 / 操作人 DN / 来源 IP / 操作 / 目标 DN / 结果。任何密码值绝不落审计。可按关键字过滤、导出。LAM 等其他客户端的写操作虽不在本工具审计内，但可通过条目修改时间 / entryCSN 感知。

## 9. 帮助中心（侧栏「帮助中心」）

### 9.1 新手引导
6 步上手任务清单（完成态实时推断）+ 5 步聚光灯界面导览（首次登录自动出现一次，可重看）。

### 9.2 LDAP 教学
9 节课程，全部用你目录里的真实数据举例：DN 与 RDN（可视化拆解）、objectClass 与 schema、属性与多值、bind 与 ACL、**过滤器语法（内嵌实验器，对真实目录执行查询，写错语法会展示服务器真实报错 + 白话解释）**、两种组、LDIF、目录树设计建议、常见误区。

### 9.3 对接指引（对接堡垒机 / 零信任 / VPN / SSO 必读）
1. **确认对外通告地址**：对方系统访问的 OpenLDAP 地址（不是本管理台网址）。
2. 选对方产品类型（5 种模板）→ **对接信息卡**：按对方表单分组的取值（服务器地址 / Base DN / 用户过滤器 / 属性映射 / 组过滤器…），逐行复制或一键复制全部，直接粘给对方管理员。
3. **创建对接专用只读账号**（强烈建议，别把 admin 给对方）：
   - 位置可选（默认 ou=services 自动创建，也可选已有部门或根）；
   - 创建后密码**只显示一次**，条目在 phpLDAPadmin 立即可见；
   - **凭据自测**：真 bind 一次，绿灯再交付；
   - 「只读」由服务端 ACL 决定，页面提供按实际 DN 生成的 olcAccess 样例 LDIF 供运维执行。
4. 底部 FAQ：搜不到用户 / 登录失败 / 部门层级丢失 / 改密不生效等常见对接问题对照。

### 9.4 术语词典
属性 / 对象类两栏，中文名 + 白话说明，可搜索。

## 10. 连接设置

查看连接档案、服务端能力探测（memberOf / ppolicy / 分页）、修改保存的凭据、清除本机密码、注销全部会话。

## 11. 员工自助改密

把 `https://<管理台地址>/password` 发给员工：账号（uid）+ 旧密码验证后自改，无需管理员参与。密码策略错误自动翻译成白话（太弱 / 与历史重复 / 改太频繁…），连续失败限流防爆破。

## 常见问题

| 问题 | 答案 |
| --- | --- |
| 我改的东西 LAM 能看到吗？ | 能，所有修改都是标准 LDAP 写，实时互见；反过来 LAM 改的这里刷新即见。 |
| 权限组删不掉最后一个成员？ | 正常：schema 要求 member 至少 1 名。先加新的再移旧的，或直接删组。 |
| 员工离职怎么处理？ | 先「禁用」观察一段时间（所有属性保留、随时恢复），确认无系统依赖后再删除。 |
| 想给堡垒机填的 LDAP 参数去哪找？ | 帮助中心 → 对接指引，信息卡逐行复制即可。 |
