# 需求清单

- 版本：v0.1（2026-09-21）
- 优先级定义：**P0** = MVP 必须；**P1** = v1.x；**P2** = v2.0 及以后
- 需求编号规则：`R<模块>.<序号>`，非功能需求 `NFR<序号>`

## 1. 背景与目标

为 OpenLDAP 提供一个中文、现代、新手可用的 Web 管理界面：

- 保留 OpenLDAP 架构本色（自由 DIT、标准 schema、无影子库）；
- 三种产品形态一体：compose 伴随部署（类原生）、独立部署对接第三方 LDAP（运维工具）、独立自助改密码入口；
- 支持 Excel 批量导入导出组织架构与人员；
- 与 LAM 等标准 LDAP 客户端可安全并存共管；
- 后续版本支持飞书 / 企业微信 / 钉钉组织与人员导入同步。

## 2. 用户角色

| 角色 | 说明 | 主要使用的功能 |
| --- | --- | --- |
| 目录管理员 / 运维 | 懂或不懂 LDAP 的 IT 人员 | 管理台全部功能 |
| 普通员工 | 企业内最终用户 | 仅自助改密码 |
| LDAP 专家 | 熟悉 schema 与 LDIF | 专家模式、原始属性编辑 |

工具自身不建用户体系：管理台登录即"用某个 LDAP 账号 bind"，工具内权限完全等于该账号在服务端 ACL 下的权限（见 R11.4）。

## 3. 功能需求

### R1 部署与连接管理

| 编号 | 需求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| R1.1 | docker compose 伴随部署 | P0 | 提供与 OpenLDAP（osixia / bitnami 镜像）同栈的 compose 样例；`depends_on` + 健康检查保证 LDAP 先就绪；LDAP 端口可不暴露宿主机，仅 Web 对外 |
| R1.2 | 环境变量预配置 | P0 | 容器读取 `LDAP_*` 环境变量（地址、base DN、bind DN 等）直接进入可用状态，跳过连接向导 |
| R1.3 | 独立部署连接向导 | P0 | 步骤化填写地址 / 端口 / TLS 方式（明文、StartTLS、LDAPS）/ bind DN / 密码，保存为连接档案 |
| R1.4 | rootDSE 自动探测 | P0 | 自动读取 namingContexts、厂商标识、supportedControls（分页、memberOf 等），自动确定 base DN 与服务端能力 |
| R1.5 | 空目录 / 存量目录分支 | P0 | 首次进入时检测目录状态：空目录 → 建库向导；已有数据 → 直接登录使用 |
| R1.6 | 多目录连接档案 | P1 | 保存多套连接档案并切换（一人管多套目录的场景） |
| R1.7 | 连接测试与诊断 | P1 | 常见连接错误中文诊断（网络不通、凭据错误、证书不受信等）及处理建议 |

## 6. 明确不做的事情（边界）

1. **不管理 slapd 服务端配置**（olc / slapd.conf、overlay 开关、复制拓扑）——只检测并只读展示，不修改；
2. **不自建用户/角色体系**——工具内权限完全等同 LDAP ACL（v2 可考虑只读角色等轻量增强）；
3. **MVP 不做 AD 深度兼容**——独立 bind 浏览只读可用即可，写操作（含改密）到 v2.0；
4. **不做多租户 SaaS**——单实例面向单套目录（多档案切换是运维便利，不是租户隔离）；
5. **不承诺回收站/撤销**——LDAP 无事务，以"预览 + 确认 + 审计"替代，文档中明确告知用户。
