## 2. spike 结论

### ① go-ldap 连接 / 分页 / modrdn —— 成立

- go-ldap/ldap v3.4.8 对 ldap://、StartTLS、ldaps:// 全支持；bind 成功/失败路径正确返回（invalidCredentials=49 可被程序化识别，用于"账号或密码错误"防枚举文案）。
- **分页控件**：自实现宽容分页循环（服务端不回应 paged control → 视为单页；cookie 不变 → 防死循环中断）。这比 `SearchWithPaging` 更稳（后者对不支持分页的服务端直接报错），对接第三方老 LDAP 时是实际优势。
- **modrdn**：改名与移动（newSuperior）均可用，子树随之迁移。
- 验证方式：`internal/ldapclient/client_test.go` 真实 go-ldap 客户端 × 进程内替身（线协议级）+ CI 中真实 OpenLDAP 集成测试（`integration_test.go`，环境变量门控）。

### ② subschema RFC4512 解析 —— 成立，已产品化

- 手写 tokenizer（引号转义/嵌套括号/$ 列表）+ 关键字驱动的 parser，覆盖：多别名 NAME、SUP 继承、`SYNTAX {len}` 限长、SINGLE-VALUE / NO-USER-MODIFICATION / USAGE、X- 扩展、同名后定义覆盖。
- fixture 为真实 OpenLDAP subschema 摘录（8 个 objectClass + 12 个 attributeType），测试 8 项断言全过；服务端路径（Subschema() → schema.Parse）亦有测试。
- 结论：**D2（动态表单）可行**，M1 可直接基于 `schema.Schema` 的 MUST/MAY + 语法映射生成表单。

### ③ excelize 中文表头 —— 成立

- 模板生成（部门/人员/填写说明三表）→ 填写 → 解析回环测试通过；行级错误精确定位（"第 N 行 / 部门路径重复 / 工号冲突 / 邮箱格式"）满足 R7.4/R7.5 要求。
- 计划引擎（planexec）的 diff 内核（按工号匹配 → create/update/error + 汇总）已实现并有测试，M3 只需补执行器。

### ④ entryCSN 冲突检测 —— 成立，已含在 API 中

- 流程：编辑页读 entryCSN → 提交时服务端再读比对 → 不一致返回 409（`directory.ErrConflict`），一致才执行属性级 Modify。
- 测试验证了完整场景：A 读 CSN → B（模拟 LAM）先改 → A 提交被拦 → A 刷新后提交成功且 **B 的修改未被覆盖**（非破坏纪律 D3 生效）。
- 真实 OpenLDAP 的 entryCSN 语义由 CI 集成测试覆盖（修改后 CSN 必变）。

## 3. 冒烟链路（验收主线）

`test/e2e/smoke_test.go` + 浏览器实测，全部通过：

1. `GET /healthz` → `{"status":"ok","ldap":"up"}`
2. 未登录访问受保护 API → 401；错误密码登录 → 401（统一文案防枚举）
3. `POST /api/v1/auth/login`（真实 bind）→ 会话 Cookie
4. `GET /api/v1/tree` → 根下 5+ 子节点（懒加载一层）
5. `GET /api/v1/entry?dn=…` → 全属性 + entryCSN
6. `PUT /api/v1/entry` 携带过期 CSN → **409 冲突拦截**；携带最新 CSN → 200 且 CSN 更新
7. `GET /api/v1/search`（分页路径）→ 全部人员
8. `POST /api/v1/entry/move`（modrdn）→ 李娜 tech → product 成功
9. `GET /api/v1/schema` → 解析后的 objectClass 列表
10. 审计日志断言：登录(成功+失败)/修改/移动均落盘，**且不含密码明文**
11. 浏览器：登录 → Vue 管理台 → 左树（懒加载）+ 人员表（LDAP 实时数据）+ 编辑抽屉（含冲突提示路径）

## 4. 环境说明（诚实边界）

- **本机无 Docker/WSL**：进程内替身承担线协议级验证；真实 OpenLDAP 行为（entryCSN 真实格式、分页控制真实应答、ACL 拒绝）由 CI 的 service 容器验证——集成测试已就绪，本地自动跳过。
- **本机无 Go**：已下载 Go 1.23.4 官方 zip 免安装解压至 `D:\work\tools\go`（不写系统路径、不加环境变量，可随时删除）。构建命令前缀 `export PATH="/d/work/tools/go/bin:$PATH"`。
- **模块代理**：`GOPROXY=https://goproxy.cn,direct`；npm 用 npmmirror。
- 替身与真实服务器的差异已在 `internal/ldaptest/server.go` 包注释中逐条声明（无 schema/ACL 校验、分页宽容、子串过滤宽松）。
- 修复过程中的真实 bug 教训（已沉淀在替身实现中）：多值 LDAP 属性必须**一次** AddAttribute 传全部值，否则客户端只读到第一个值；bind 错误必须用 BindResponse 而非通用 LDAPResult，否则客户端报"网络错误"而非 49。
